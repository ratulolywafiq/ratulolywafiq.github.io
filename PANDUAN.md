# Website Ratuloly Wafiq

Paket berisi `index.html`, `styles.css`, `script.js`, ikon `assets/mark.svg`, `robots.txt`, dan `sitemap.xml`.

## Personalisasi foto sebelum publikasi
Saat ini bagian foto masih berupa placeholder desain, karena foto asli belum tersedia sebagai berkas di sesi pembuatan ini. Tambahkan foto milik sendiri ke folder `assets`, lalu ganti blok `.photo-placeholder` di `index.html` dengan gambar, misalnya:
`<img src="assets/foto-profil.jpg" alt="Ratuloly Wafiq dalam kegiatan relawan">`
Gunakan foto-profil.jpg untuk hero, gempa-flores.jpg, pendidikan-pelosok.jpg, dan air-bersih.jpg untuk dokumentasi kegiatan. Pastikan izin penggunaan foto orang lain sudah diperoleh.

## Publikasi gratis via GitHub Pages
Alamat website yang disiapkan: https://ratulolywafiq.github.io/

1. Dengan bantuan orang tua/wali, buat akun di https://github.com jika belum punya.
2. Buat repository **public** bernama persis `ratulolywafiq.github.io` (username GitHub kamu).
3. Unggah isi folder ini ke root repository.
4. Buka Settings → Pages. Pada Build and deployment, pilih Deploy from a branch, branch `main`, folder `/ (root)`, lalu Save.
5. Setelah proses selesai, alamat situs berbentuk `https://ratulolywafiq.github.io/`.
6. File `robots.txt` dan `sitemap.xml` sudah disesuaikan dengan username `ratulolywafiq`.

## Google Search Console
1. Buka https://search.google.com/search-console.
2. Tambahkan properti **URL prefix** dengan alamat GitHub Pages yang sudah aktif.
3. Ikuti metode verifikasi HTML tag atau file HTML yang ditawarkan Google. Jika memilih HTML tag, masukkan tag ke dalam `<head>` `index.html`, unggah ulang, lalu klik Verify.
4. Setelah terverifikasi, buka Sitemaps dan kirim `sitemap.xml`.
5. Gunakan URL Inspection untuk meminta pengindeksan halaman utama.

Catatan: pengindeksan dan peringkat di Google tidak dijamin instan. Jangan membagikan kata sandi atau kode verifikasi kepada siapa pun.
